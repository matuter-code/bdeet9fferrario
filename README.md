 Ejercicio práctico: “Gestión de datos de estudiantes”

1.. EJERCICIOS INTRODUCTORIOS::

 .. ¿Qué es un tipo de dato?  

 .. ¿Qué significa que un lenguaje sea dinámicamente tipado o estáticamente tipado? ¿Cuáles son sus pros y sus contras?

 .. ¿Qué significa que un lenguaje sea fuertemente tipado o débilmente tipado? ¿Cuáles son sus pros y sus contras?

 ..  ¿Qué quiere decir que un programa sea interpretado o compilado?

RESPUESTAS:

1.. un tipo de dato es el formato que le podemos asignar a un dato o informacion para que la computadora y el interprete sea capaz de comprender que estamos intentando hacer y que debe de hacer con el dato ingresado o que tiene guardado en alguna variable 
2.. 
- Estáticamente tipado: el programa toma directamente todo el código y traduce línea
por línea para verificar que cada dato sea legible antes de ejecutarlo

- VENTAJAS Y DESVENTAJAS: al traducir línea por línea, el programa se ejecuta mas lento
pero esto le permite darse cuenta en que línea hay un error asi permitiendo que el
programa le avise al usuario exactamente que línea es la que tiene un error o que
variable no esta definida, etc (básicamente cualquier error)
____________________________________________________________________________________________
- Dinámicamente tipado: este toma todo el programa y directamente lo traduce y
ejecuta
- VENTAJAS Y DESVENTAJAS: este permite una ejecución mas rápida pero no puede
indicar que línea esta mal ya que ejecuto todo de una sin permitir saber que línea
específicamente esta mal

3..- Cuando hablamos de que un lenguaje sea fuertemente tipado o débilmente tipado
hablamos de qué tan estricto es el lenguaje cuando querés mezclar tipos distintos
- Fuertemente tipado: al momento de mezclar tipos de datos es MUY estricto, no
supone solo traduce y lee, por ejemplo si intentamos escribir: print(5+”10”) como
intentamos mezclar 2 tipos de datos distintos en una cuenta Python va a dar un error

- VENTAJAS Y DESVENTAJAS: permite un código mas prolijo y funcional pero necesita
una sintaxis escrita y necesita que siempre utilices conversiones de tipo de datos
____________________________________________________________________________________________
- Débilmente tipado: este es todo lo contrario, puede mezlcar tipos de datos

- VENTAJAS Y DESVENTAJAS: permite una sintaxis mucho mas variada y flexible
(también fácil de usar) pero a cambio es menos prolijo y si cometes un error el
programa no te avisara si no que directamente lo ejecutara y te dejara a tu suerte

 Qué quiere decir que un programa sea interpretado o compilado?

- Intepretado: traduce todo el código directamente y lo pasa a un lenguaje
maquina para ejecutarlo
- Copilado: traduce el código directamente al momento de ejecutarlo línea por
línea
